# Design System Notes for Stitch Generation

Please follow these visual guidelines closely when generating UI screens.

## Global Tokens

- **Color Mode**: Light mode by default, with dark mode support.
- **Font**: "Inter" (Clean, modern sans-serif suitable for academic and professional use).
- **Roundness**: `ROUND_EIGHT` (Subtle rounded corners, 8px).
- **Primary Color**: `#1D4ED8` (A strong academic blue).
- **Secondary Color**: `#F59E0B` (A complementary warm gold/amber for highlights and warnings).

## Vibe & Aesthetic

- **Clean and Professional**: It's a campus organization tool, so it should look trustworthy but modern.
- **Accessible**: High contrast text, clear hierarchy, easily tappable buttons.
- **Layouts**: Use ample whitespace to prevent clutter, especially on the dashboard and data-heavy pages.
- **Card-based**: Use distinct cards to separate information like upcoming events, petty cash balances, or member stats.
